# Complete WordPress blocks

The website review pane's Copy HTML button reads the complete `*-complete-block.html` file for the selected page. Paste it as a replacement for that page's existing WordPress Custom HTML block. Each file is versioned in Git, so the complete code for earlier versions remains available in commit history. The local preview loads these same blocks inside the live site frame.
